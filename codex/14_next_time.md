# 14: "양보"를 "이번엔 빼도 돼, 다음엔 먼저"로 바꾸기

사용자 결정: "양보"는 손해 보는 느낌이라 쓰지 않는다. **포기가 아니라 이번만 빼는 것**, 그리고 **뺀 사람은 다음엔 먼저 고른다**는 틀로 사용자에게 보이는 모든 문구를 바꾼다. 코드의 식별자(relaxations, muted, ledger 등 변수·키·API 경로)는 바꾸지 마라. 문구만.

**문구 규칙: 줄표(—, –)와 가운데 점(·) 금지.** 이모지 금지.

## 바꾸는 말 (vooy와 같은 단톡방 말투. "다음에 맞출게", "다음 여행 우선권", "다음으로 미룬다"는 어색하다는 사용자 피드백으로 쓰지 않는다)

틀: 포기가 아니라 **이번만 빼고, 뺀 사람은 다음엔 먼저 고른다.**

| 지금 | 바꿀 말 |
|---|---|
| 이 말은 양보할게 (2단계 체크리스트 토글) | 이번엔 빼도 돼 |
| (토글된 행 알약) 양보 | 이번엔 뺌 |
| 숲체험을 넣으려면 하나를 양보해야 해요 | 이대로는 안 돼요. 하나만 빼면 숲체험이 들어가요 |
| 서연의 '카페 1곳'을 양보 | 서연의 '카페 1곳'을 빼면 |
| 양보 후 59 : 60으로 더 고르게 | 빼면 59 대 60, 더 고르게 |
| 추천 안 선택 버튼 | 이걸로 할게 |
| 양보 장부 | 다음엔 먼저 (사람 색 점과 횟수: 지민 1, 서연 0) |
| 지난번 익선동에선 지민이 양보했어요. 이번엔 서연 차례 | 지난번 익선동에선 지민이 하나 뺐어요. 이번엔 서연 차례예요 |
| 이번 양보: 서연 '카페 1곳', 다음엔 지민 차례 (4단계) | 이번엔 뺐어요: 서연의 '카페 1곳'. 다음엔 서연이 먼저 골라요 |
| (합의 화면 헤드라인에 쓸 수 있으면) | 서연 덕분에 둘 다 OK |
| 양보 후 (계획 라벨) | 하나 뺀 뒤 |
| 꼭 지킬 조건도, 말한 사람이 양보하면 바꿀 수 있어요 | 꼭 지킬 조건도, 말한 사람이 이번만 빼면 바뀔 수 있어요 |

- 장부 의미: 이번에 뺀 사람은 다음엔 먼저 고른다. 엔진 로그 `다음엔 먼저 지민 1, 서연 0`.
- 발표 캡션 `CAPS`에 "양보"가 있으면 같은 틀로.
