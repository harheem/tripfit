## 바꿀 모습 (TripFit 데모 문법 그대로)

- **무대**: 페이지 배경 `--stage #E7F1EC`. 가운데 **아이폰 프레임**(검은 베젤 라운드, 상단 다이내믹 아일랜드, 상태바 시각 "12:58"과 신호·와이파이·배터리 아이콘은 인라인 SVG), 화면 안 바탕 네이비 `#0E2A3A`. 프레임 아래 페이지 점 대신 컨트롤 알약(아래)
- **방 머리 블록**(라임 `#D6F23B`, 위 모서리 화면에 붙음): 왼쪽 TripFit 로고(두 원 겹친 마크 + "TripFit" 굵게), 오른쪽 작은 "vooy 단톡방". 큰 제목 두 줄 "성수 / 토요일 나들이"(TripFit의 "성수 반나절"과 같은 크기·굵기), 오른쪽에 겹친 아바타 원 3개(민·지·서, 각 사람 색)
- **일정 블록**(분홍, 머리 블록과 .cut/.tab로 맞물림): 왼쪽 네이비 원 날짜 "8 NOV", "오늘 일정 13:00~18:00, 성수역 출발", 오른쪽 외곽선 알약 "미정" → 결과가 나오면 "정함"
- **말 블록**: 말풍선이 아니라 **가로 전체 파스텔 블록**(TripFit 데모처럼). 민지 = 분홍 왼쪽 정렬, 지훈 = 하늘 왼쪽 정렬, 서연 = 피치 오른쪽 정렬(나). 블록 안: 네이비 원 이니셜 + 작은 이름 + 본문 16px/600. 블록 사이 4px 네이비 틈
- **TripFit 말**: 라임 블록, 위 경계에 걸친 네이비 `.flag` 라벨 "✓ TripFit". 본문은 결과 첫 줄. 그 아래 MCP Apps 위젯 iframe이 이어지는 블록 자리(위젯 카드는 자체 네이비 카드라 네이비 바탕 위에 바로 놓는다. 좌우 여백은 다른 블록과 같게)
- **도구 호출 표시**: 다이내믹 아일랜드가 펼쳐지며 말한다(TripFit 데모의 시스템 피드백 방식). 호출 중 "TripFit propose_plans 호출 중"과 스피너 → 끝나면 "propose_plans 2.0초"로 바뀐 뒤 2초 뒤 접힘. 대화 흐름 안에도 작은 네이비 알약 기록 한 줄(크림 글자) 유지
- **입력 중 표시**: TripFit 데모의 흐린 블록 + 점 3개
- **입력창**(화면 아래, 네이비 위): 크림 알약 입력 + 라임 원 보내기 버튼(↗). 플레이스홀더 "@TripFit 코스 짜줘"
- **컨트롤**(프레임 아래 무대 위): 외곽선 알약 "처음부터", "다음", "조건 충돌 해보기". 그 아래 접는 "기술 정보"(호출 로그, arguments) 유지
- **정직 표기**: 프레임 위 무대에 작은 줄 "vooy 단톡방을 재현한 데모. 계산과 위젯은 공개 MCP 서버 실호출. 장소는 성수 샘플" 유지
- 지금 있는 "단톡 라이트 / DM 다크" 스킨 토글과 폭 선택은 **삭제**(TripFit 한 가지 모습으로). 관련 죽은 코드도 삭제
- 모션: 블록 등장 = 아래에서 튀어 오름(TripFit 스프링 `linear()`), 아일랜드 펼침 스프링, `prefers-reduced-motion` 즉시
- 폰 프레임은 데스크톱에서 높이 맞춰 가운데, 휴대폰으로 직접 열면(폭 480px 이하) **프레임 없이** 화면 전체를 쓴다
