## A. 위젯 안 덜어내기 (`ui/board.html`의 inline 카드만)

사용자: "여전히 MCP Apps 내부가 빽빽하다." `codex/10_breathe.md`의 "새 inline 카드" 절을 그대로 구현하라. 핵심만:
- inline에서 **사람 타일 3개 삭제** → 네이비 위 한 줄 "● 민지 100  ● 지훈 100  ● 서연 100"(색 점 8px, 12px)
- inline에서 **안 탭 삭제**(크게 보기에서만)
- 버튼은 "이 안으로 정하기" 하나(라임, 가로 전체). "크게 보기 ›"는 아래 출처 줄 오른쪽 작은 텍스트 링크
- 머리줄 오른쪽 "3안, 1.9초" 알약 삭제(출처 줄로)
- 블록 안 패딩 16px, 블록 사이 6px, 목표 높이 260~300px
- 전체 보드(fullscreen/web)는 건드리지 마라

## B. /chat 겉을 "메신저 단톡방"처럼 (`ui/chat.html`)

사용자: "겉은 살짝 카톡방처럼 보이게. 지금은 TripFit 서비스 안에 채팅 기능이 따로 있는 것 같다." 즉 **TripFit 앱 화면이 아니라, 평소 쓰는 메신저 단톡방에 TripFit이 불려 온 모습**이어야 한다. 카카오톡 상표·로고·노란 말풍선은 쓰지 않는다(사칭 금지). 일반 메신저 문법으로:
- 폰 프레임과 무대 배경은 유지
- 폰 화면 안: 라임 TripFit 머리 블록, 분홍 일정 블록, 파스텔 가로 말 블록 **삭제**
- 상단 방 바: 흰 바탕, 왼쪽 ‹ 뒤로 아이콘, 가운데 "성수 토요일 나들이" 굵게 + 회색 "4"(인원), 오른쪽 검색·메뉴 아이콘(인라인 SVG)
- 대화 배경: 옅은 회청색 `#BACEE0` 계열
- 다른 사람 말: 왼쪽 정렬, 둥근 사각 프로필(색 이니셜), 위에 작은 이름, **흰 말풍선**(라운드 12px), 옆에 작은 회색 시각 "오후 1:02"
- 내 말(서연): 오른쪽 정렬, 말풍선은 **연한 라임**(`#E8F7A8` 정도. 노랑 금지), 시각은 왼쪽
- TripFit: 다른 사람처럼 왼쪽 정렬. 프로필은 라임 원에 TripFit 마크, 이름 "TripFit". 흰 말풍선 텍스트 + 그 아래 위젯 카드(말풍선 폭과 같은 정렬)
- 도구 호출 표시: 대화 가운데 작은 회색 반투명 알약 "TripFit이 propose_plans 호출 중" → "propose_plans 1.7초"(날짜 구분선 같은 시스템 메시지 스타일). 다이내믹 아일랜드 연출은 삭제
- 입력 바: 흰 바탕, 왼쪽 + 아이콘, 가운데 회색 둥근 입력칸, 오른쪽 보내기 버튼
- 무대 위 정직 표기 줄과 아래 컨트롤 알약·기술 정보는 유지
- 폭 480px 이하에서는 프레임 없이 전체 화면
