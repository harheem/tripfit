네이비·파스텔 벤토 카드와 메신저 미리보기를 적용했습니다.

| 채팅 맥락 | 반영 |
|---|---|
| 좁은 말풍선 | 기준 280px, 미리보기는 폰 폭의 72% |
| 제한된 높이 | 코스 최대 3곳, 긴 경우 행 축약 |
| 라이트·다크 | 같은 네이비 카드, 두 채팅 스킨 |
| 개인 화면 조작 | 탭은 로컬 비교, 결정은 `ui/message` |
| 빠른 답장 | 36px 알약, 실제 타깃 40px |
| 새 결과 | 새 iframe 추가, 이전 카드·선택 유지, rev 표시 |
| 텍스트 알림 | 첫 줄에 결과와 사람별 만족도 |
| 오탭 방지 | inline 슬라이더·드래그·가로 스크롤 제거 |

280px **예상 높이**는 정상 340px / 불가능 310–316px / diff 364px입니다. 실측값은 아닙니다.

첫 줄 예:
> 다들 OK인 코스 3안 — "민지" 100 · "지훈" 100 · "서연" 100

흰 카드 스타일, 원형 게이지, 세그먼트 thumb, 펼치는 상세 영역과 이전 압축 코드를 삭제했습니다.

검증은 **pytest 56개 통과**, 보안 grep **0건**, 스크립트 구문 검사 통과입니다. DOM 동작도 확인했습니다. 브라우저 실행·연결 제한으로 실제 화면, 폭별 높이, 터치는 확인하지 못했습니다.
