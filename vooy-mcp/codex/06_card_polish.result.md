inline 카드와 미리보기를 수정했습니다. 전체 보드 CSS·마크업은 그대로 유지했습니다.

1. 연한 막대 → 진한 색 원형 게이지와 숫자 동기화
2. 기호 카운트 → 탭해서 읽는 조건 목록과 양보 칩
3. 반복 샘플 배지 → 푸터 한 곳으로 통합
4. 라임 버튼 경쟁 → 회색 세그먼트와 텍스트 버튼
5. 상태별 헤드라인과 동네·시간·거리 정보 추가
6. 글머리표 코스 → 카테고리 아이콘·점선·보행 시간 동선
7. 여백·글자 위계·그림자·다크 테마 정리

미리보기는 예산 양보 뒤 **새 카드**를 추가하며, 카드 내부 조작은 해당 인스턴스에만 응답합니다.

예상 높이는 **300px에서 420–440px, 360px에서 410–440px**입니다. 공간이 부족하면 코스를 요약합니다.

검증: **pytest 54개 통과**, 보안 검색 **0건**, 구문 검사 통과, DOM 검사 **145개 통과**.

실제 화면 높이·모션·fullscreen 시각 검증과 실제 서버 undo·양보 성공 응답은 미확인입니다. 로컬 서버 실행과 브라우저 연결이 제한됐으며, 자동 승인 검토가 Chrome 접근을 “사용 승인 없음”으로 거절했습니다.
