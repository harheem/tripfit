# 06 — 대화 카드 디자인 품질 올리기 (inline 카드 재디자인 + 미리보기 현실화)

너는 `vooy-mcp/` 폴더에서 일한다. 첨부 이미지 `before_chat_card.jpg`가 지금 `ui/board.html`의 inline 대화 카드다. 사용자 평가: **"디자인·레이아웃 퀄리티가 떨어져 보인다."** 기능은 맞으니 **시각 품질**을 제품 수준(토스·애플 위젯 정도의 정돈감)으로 올린다. `before_full_board.jpg`는 전체 보드(fullscreen/web)로, 이번엔 손대지 않는다.

## 지금 카드의 문제 (리뷰어 진단)

1. 막대가 연한 파스텔 실선이라 100%인데도 비어 보인다. 숫자만 크고 시각 근거가 약하다
2. "✓1 ◐1 ⤺1" 같은 기호 카운트는 뜻이 안 읽힌다
3. "샘플" 배지가 코스 줄마다 반복돼 시끄럽다
4. 라임 알약 3개(안 선택)와 라임 큰 버튼(크게 보기)이 같은 무게로 경쟁 → 시선이 갈 곳이 없다
5. 핵심 메시지("다들 OK인가? 누가 얼마나 양보했나?")를 한 줄로 말해 주는 헤드라인이 없다
6. 코스가 글머리표 목록이라 "동선"으로 안 보인다. 장소 종류 구분도 없다
7. 간격·글자 크기가 촘촘하고 위계가 평평하다

## 새 레이아웃 (폭 300~400px, 높이 목표 360~420px, 최대 440px)

카드: 흰 면(다크는 #18212b), 라운드 20px, 1px 테두리 rgba(15,23,42,.06), 그림자 `0 1px 2px rgba(15,23,42,.06), 0 8px 24px rgba(15,23,42,.08)`, 안쪽 여백 16px. 8px 간격 그리드.

1. **머리줄**(높이 20px): 왼쪽 18px 앱 마크(라임 원 + 저울 아이콘) + "TripFit" 13px/600 회색, 오른쪽 "4.0초 계산" 12px 회색. 알약 금지
2. **헤드라인**(카드의 주인공):
   - 큰 줄 20px/700: 상태에 따른 한 문장 — 모두 90% 이상 "다들 OK인 코스예요" / 한 명이라도 70% 미만 "○○ 쪽이 조금 양보한 코스예요" / infeasible "이대로는 안 돼요" / diff 있으면 "다시 계산했어요"
   - 작은 줄 13px 회색: "성수 · 13:00–18:00 · 3명 · 4곳 · 도보 1.9km"
3. **사람 게이지 줄**: 사람마다 **원형 게이지**(지름 52px, 굵기 5px, 트랙은 사람 색 20% 불투명, 채움은 사람 색의 진한 톤(아래 토큰) — 가운데 이니셜 15px/700), 아래 이름 12px, 그 아래 % 15px/700 tabular-nums. 3명이면 가로 균등 배치, 4명 이상이면 4개 + "+N". `pct:null`은 점선 트랙 + "조건 없음". 양보한 항목이 있는 사람은 게이지 오른쪽 위에 작은 "양보" 칩(회색 11px)
   - 게이지를 탭하면 그 사람 항목 리스트가 카드 아래로 펼쳐짐(항목 앞 아이콘: 충족 ✓ 원, 부분 반원, 못 함 ✕, 양보 ↺, 확인 불가 ?), 다시 탭하면 접힘. 펼친 상태도 높이 한도 안에서(항목 최대 4줄)
4. **안 선택**: 하나의 **세그먼트 컨트롤**(회색 트랙 #f1f3f5, 높이 36px, 라운드 12px, 선택 칸은 흰 thumb + 그림자, 글자 13px/600). 라임 금지. thumb은 선택 이동 시 220ms 슬라이드
5. **코스**: 가로 타임라인이 아니라 **세로 2열 그리드 미니 카드** 대신 → **세로 동선 리스트**, 줄마다: 왼쪽 시각 12px tabular 회색 / 가운데 카테고리 아이콘(인라인 SVG 16px, 원형 배경 24px — 전시·카페·식당·소품샵·골목·공원·체험 7종을 각각 다른 파스텔 배경) + 장소명 14px/500 말줄임 / 줄 사이 세로 점선 연결과 "도보 6분"(walk_m/70 반올림) 11px. 최대 4곳, 넘으면 "+1곳 더" 텍스트 링크(크게 보기와 같은 동작)
6. **바뀐 점 칩**(diff 있을 때만, 헤드라인 바로 아래): "+ 어니언 성수" 초록 칩, "− 연무장길 골목" 회색 취소선 칩, 최대 3개
7. **푸터**: 왼쪽 11px 회색 "실제 계산 · 장소는 성수 샘플 · 도보 추정"(샘플 표기는 여기 한 번만, 줄마다 배지 금지), 오른쪽 텍스트 버튼 "크게 보기 ›" 13px/600 진한 회색, undo 가능하면 그 왼쪽에 "되돌리기" 같은 스타일. **큰 라임 버튼 금지**
8. **infeasible**: 헤드라인 "이대로는 안 돼요" + 작은 줄 "한 가지만 양보하면 돼요". 게이지 줄 생략, 대신 양보 선택지 카드 최대 3개(흰 면 안 회색 #f8f9fa 블록, 라운드 14px, "지훈 · 걷기 1km 조건을 풀면" 14px/600 + "모두 최소 100%" 12px, 오른쪽 "이걸로" 작은 알약 버튼(진한 남색 바탕 흰 글자))

## 토큰

- 글자: 시스템 스택 그대로. 숫자 `font-variant-numeric: tabular-nums`. 글자색 #111827 / 보조 #6b7280 / 약 #9ca3af(라벨 전용)
- 사람 색(트랙/채움): pink #fbcfe8/#db2777, sky #bae6fd/#0284c7, peach #fed7aa/#ea580c, butter #fde68a/#ca8a04, mint #a7f3d0/#059669, lilac #ddd6fe/#7c3aed
- 다크 테마: 면 #18212b, 글자 #f3f4f6, 보조 #9ca3af, 트랙 불투명도 30%
- 라임은 앱 마크와 diff 하이라이트에만

## 모션 (05 규칙 유지 + 다듬기)

- 게이지 채움: 첫 표시 0→값 500ms `cubic-bezier(.2,.8,.2,1)`, 갱신 시 이전값→새값 400ms. % 숫자 카운트업 동기화
- 세그먼트 thumb 슬라이드 220ms, 안 바꾸면 코스 리스트 크로스페이드 160ms + 게이지 재채움
- 펼침/접힘 높이 200ms(그 뒤 size-changed 1회)
- reduced motion이면 전부 즉시

## 미리보기 현실화 (`ui/preview.html`)

- MCP Apps에서 **모델이 새로 도구를 부르면 새 메시지에 새 위젯 인스턴스**가 생긴다. "예산은 좀 넘어도 돼" 이후 vooy의 `adjust_plan` 결과는 **대화 맨 아래 새 카드**로 나와야 한다(기존 카드는 그대로 둠). 카드 안 버튼이 부른 `tools/call`(이걸로·되돌리기)만 그 카드 자리에서 갱신
- 미리보기에서 "크게 보기"가 실제로 fullscreen 오버레이로 열리는지 확인하고, 닫기로 inline 복귀
- vooy 텍스트 말풍선은 결과 `content` 전체가 아니라 첫 줄 + "아래 카드에서 비교해 보세요" 정도로 짧게(실제 vooy는 자기 말투로 요약)
